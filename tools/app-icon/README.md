# أيقونات التطبيق = شعار المقهى

**القاعدة:** أي تطبيق (PWA) نعمله لموقع من مواقعنا، أيقونته هي شعار المقهى نفسه: نفس النص والخط والألوان والخلفية تبع شعار رأس الموقع. وصفحة «لا يوجد اتصال» وزر التثبيت بنفس الهوية.

1. اقرأ شعار الموقع (الـ HTML والـ CSS): الخط، اللون، الخلفية، السطر الصغير تحته وتباعد حروفه.
2. اكتب ملف هوية في `brands/<اسم-الموقع>.json` (انظر `daily-dose.json` و `mr-black.json`).
3. شغّل:

```
NODE_PATH=C:/Users/acer/Desktop/MrBlack-Video/node_modules node render.js brands/<اسم>.json <مجلد-icons>
```

الناتج: `icon-192.png`، `icon-512.png`، `icon-maskable-512.png` (أندرويد، بهامش آمن)، `apple-touch-icon.png` (آيفون، مربع).
